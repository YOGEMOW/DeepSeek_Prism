# 五模式 --detail 输出规范

以下规范仅在 `--detail` 模式下使用。默认模式始终输出 VEP/1 紧凑证据包。所有输出遵循：只描述图片中可见的事实，不确定处标注 `(~)` 或 `[截断]`，不做推测与主观评价，输出语言与用户提问一致。

## 模式优先级

报错日志 C > 图表数据 E > 问题定位 B > 页面还原 A > 文本/对话提取 D（默认）。多张图片逐张调用，最后输出汇总表。

## A 页面还原（UI 截图 / 设计稿）

按以下六节输出：

1. **A1 页面整体概述**：页面类型、整体色调、背景、字体族、固定区域（顶部导航/侧边栏/底栏）。
2. **A2 ASCII 布局图**：60–80 字符宽，用 `+` `-` `|` 绘制嵌套盒子，标注元素名与尺寸（如 `w: 240px`）。
3. **A3 元素逐项描述**：位置、尺寸（估算标 `~`）、内容、样式（背景色/文字色/字号/字重/边框/圆角/内边距/阴影/图标）、交互状态（可点击/输入/禁用/悬停）、状态（默认/激活/禁用）。
4. **A4 颜色与设计 Token**：主色/辅助色/强调色/背景色/文字色/边框色/成功警告错误色，无法精确时给近似值并标注 `(~)`。
5. **A5 页面文本清单**：从上到下、从左到右列出所有可见文本。
6. **A6 响应式状态备注（可选）**：移动端差异、悬停/展开状态、多状态并存时分别描述。

## B 问题定位与修复

每个被标记/圈出的问题区域独立输出：

1. **B1 识别标记**：标记方式（红框/圆圈/箭头/手绘/文字注释）与指向区域。
2. **B2 问题描述**：当前表现、预期表现、具体差异点。
3. **B3 原因分析**：只列可能的直接原因（CSS 属性值、定位偏移、层级、文字溢出、颜色错误等）。
4. **B4 修复建议**：具体修改方向与目标样式值；注明连带影响与风险。

## C 报错日志提取

1. **C1 日志文本**：逐字逐句提取所有可见日志，保留原始换行、缩进与特殊字符；不得截断长堆栈、不得改写内容；被截断/遮挡处标注 `[截断]`。
2. **C2 关键信息摘要**：错误类型、错误消息、首个出错位置（文件:行号）、涉及的关键文件。

## D 文本/对话提取（默认）

1. **D1 文本全量提取**：按区域组织原文，标注区域位置/角色。
2. **D2 结构分析**：内容类型（对话/文档/菜单/通知/表格）、角色或参与者、层级关系。
3. **D3 内容关系（对话时）**：对话主题、消息序列（角色 + 摘要）、关键信息点。
4. **D4 元信息**：字体样式、特殊标记（提及/标签/链接/表情）、时间戳格式。
5. **D5 表格提取**：表格标题、Markdown 表格、行数/列数、合并单元格与着色等特殊格式；识别不清的单元格标 `(~)`。

## E 图表数据提取

1. **E1 图表类型与概述**：类型（折线/柱状/饼图/散点/雷达/热力/面积）、标题、坐标轴名称、图例项。
2. **E2 数据提取**：每个系列列出可见数据点与标签；无刻度时给相对比例描述（如“约占整体 1/3”）。
3. **E3 趋势与关键发现**：一句话趋势、极值（最高/最低）、变化率、明显异常点。
4. **E4 元信息**：注释/标注、误差线/置信区间、颜色语义（红=下跌、绿=上涨）。

## 多图汇总

```text
| # | 文件名 | 模式 | 关键发现 |
|---|--------|------|----------|
```

若多图是同一页面不同断点（桌面/移动），额外输出响应式差异表。

## 异常处理

| 情况 | 处理 |
| --- | --- |
| 图片不存在或无法读取 | `[ERROR] 无法读取: <path> — <原因>`，继续处理下一张 |
| 图片内容模糊/分辨率过低 | `[WARNING] 图片内容不清晰，以下为最佳推测` |
| 文件非图片类型 | `[SKIP] <path> 非图片文件` |
| 未提供图片路径 | `[INFO] 未找到需分析的图片路径` |
| 模式无法判断 | 默认模式 D |
